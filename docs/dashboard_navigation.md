# 대시보드 화면 구성

기존 표시 항목과 설정 입력, 실행 기능을 유지하면서 화면을 탭으로 나눴습니다.
이번 변경은 화면 구성에만 해당하며 매매 규칙이나 자동 실행 일정은 변경하지 않습니다.

| 탭 | 기존 항목의 위치 |
| --- | --- |
| 현황 | Runtime, Objective, 계좌 요약, 보유종목 점검과 위험 상태 |
| 분석 | Latest Analyses의 종목 코드/이름/순위/판단/주문/보고서/LLM, Candidate Ranking |
| 중장기 | 독립 수동 종목 탐색, 보유 관점/종목/LLM 선택, 진행 상태, 저장 결과와 근거 |
| 거래 내역 | 모의/실계좌 조회, 잔고와 보유주식, 일/주/월/년 수익률, 계좌 주문, 최근 청산 주문 체결 확인, 최근 매매 |
| 실행 | 수동 실행, 실행 중/대기 작업, 자동 분석 일시정지, 작업 충돌 시 중단/대기 선택, 보유종목 관리 등록 |
| 설정 | LLM, 자본금과 주문, 후보 종목과 뉴스, 단타 및 청산 기준, 운영 시간과 경로 |

## 접기와 조회

- 설정은 다섯 개 접기 영역으로 구분합니다. 닫힌 영역의 값도 함께 저장됩니다.
- 분석 판단의 전체 원문, 보고서 경로, LLM 경로와 기존 진입 점검 항목은 펼쳐서 확인합니다.
- 분석 탭에서 **분석 요약 파일 경로**를 펼친 뒤 경로를 클릭하면 대시보드 팝업에서 해당 JSON 전체 내용을 확인합니다. 닫기 버튼 또는 Escape로 돌아갑니다. 자동 갱신 중에도 팝업 내용은 유지됩니다.
- Candidate Ranking에는 단타 후보 선정에 사용한 코스피200 구성목록의 종목 수·기준일·출처, 후보 없음/등록 문제, 한글 별칭 부족 경고를 표시합니다. 중장기 탭에 등록한 목록을 공유하며 이전 결과는 당시 저장 정보대로 표시합니다.
- 중장기 탭에는 마지막 CSV의 파일명·조회 기준일·등록 일시(한국 시간)와 종목 수를 표시합니다. 등록한 목록은 다음 CSV 등록까지 단타·중장기 분석에서 계속 사용합니다. 이전 자료의 파일명·정확한 등록 시각은 미기록으로 표시합니다.
- 모의 거래 내역은 계좌 장부 체결과 예전 주문 계획을 구분합니다. 주문 금액/수량 옆에 체결 수량·체결가·처리 후 현금·보유 수량을 표시하고, 계좌 주문 표에는 비용과 실현손익도 표시합니다. [모의계좌 처리 기준](account_dashboard.md)을 참고하세요.
- 요약 열람은 기존 로그인 권한을 사용하며, 생성된 모의/실투자 요약 JSON만 허용합니다. 없는 파일, 손상된 JSON, 2 MB 초과 파일은 안내 메시지를 표시합니다.
- 매매/주문 내역에 종목 또는 날짜 필터와 10행 단위 페이지 이동을 제공합니다. 필터는 **서버에서 이미 조회된 내역**에 적용하며 전체 과거 내역을 새로 가져오는 기능은 아닙니다.
- 계좌 요약은 기존 계좌 조회 결과를 복사해서 보여줍니다. 추가 계좌 API 요청을 발생시키지 않습니다.
- 모바일은 하단 탭 메뉴를 사용하며 넓은 표는 표 영역 안에서 가로로 스크롤합니다.

## 화면 상태와 저장

- 자동 갱신 중에도 활성 탭, 접기 상태, 내역 필터와 페이지를 유지합니다.
- 탭별 스크롤과 접기 상태는 브라우저 탭의 세션에 저장합니다. 설정 입력값은 브라우저 저장소에 저장하지 않습니다.
- 설정을 변경하고 다른 탭으로 이동하면 확인 메시지를 표시합니다. 이동을 선택해도 입력은 유지되지만 서버에 반영하려면 기존 저장 버튼을 눌러야 합니다.
- 저장하지 않은 상태에서 페이지를 닫거나 로그아웃하면 확인을 요청합니다.
- 운영 모드, 갱신 시각, 진행 작업과 주요 위험 경고는 상단에서 확인할 수 있습니다.

## 적용

실행 중인 기존 `main.py`를 정상 종료한 뒤 평소 사용하던 실행 파일 또는 명령으로 다시 시작하고 브라우저를 새로고침합니다.
매매 작업이 진행 중이라면 먼저 현재 작업과 주문 상태를 확인한 후 재시작합니다.

중장기 탐색은 [별도 가이드](long_term_research.md)를 참고하세요.
