# 단타 전략 비교 사용 안내

2026-11-03 기준. 기존 매매 전략을 유지하면서 새 진입 기준을 **주문 없이 비교**하는 1차 구현이다.
비교는 Python 계산으로 수행하며 OpenAI·Ollama를 호출하지 않는다. 기존 뉴스 분석의 LLM 설정은 그대로다.

## 시작 방법

1. 실행 중인 프로그램을 정상 종료한 뒤 이 검증 프로젝트의 `Start-DryRun.command`를 다시 실행한다.
2. 대시보드에 로그인하고 **전략 비교 → 저장 자료 비교**를 누른다.
3. 새 관측을 쌓으려면 **설정 → 선정 후보 5분 비교 관찰 (주문 없음)**을 켜고 저장한다.
4. 다음 후보 선정부터 등록 코스피200 안의 선정 후보 최대 3개를 관찰한다. 기존 자동 후보 선정·매매 주기는 바꾸지 않는다.
5. 장 마감 복기가 새로 완료되면 저장 자료 비교도 자동 실행한다. 이미 복기가 완료된 날은 버튼으로 비교한다.

5분 관찰은 기본 OFF다. 켜면 Toss 시세 조회는 추가되지만 뉴스 LLM 호출과 주문은 추가되지 않는다.
명령행에서도 `--strategy-observation` 또는 `--no-strategy-observation`으로 지정할 수 있다.
기존 실행기나 실투자 프로세스는 이 기능 설치만으로 재시작되지 않는다.

## 비교하는 기준

| 비교군 | 계산과 범위 |
| --- | --- |
| 현재 전략 | 각 관측 당시 저장 설정으로 기존 기술 진입 규칙을 재평가한다. 뉴스·계좌 판정은 포함하지 않는다. |
| 동일 시간대 거래량 | 기존 거래량 검사만 같은 세션 경과 시간의 과거 5분봉 평균 대비 거래량으로 바꾼다. 나머지 가격 패턴·위험 검사는 유지한다. |
| 돌파 후 재확인 | 직전 15분 고점을 넘은 완성 5분봉의 기준선을 고정하고, 이후 최대 3봉 안에서 첫 지지 재시험을 찾는다. 기존 거래량 검사는 유지한다. |

시간대 거래량은 **직전 최대 20개 저장 거래일 중 최소 10개 유효 일수**가 필요하다.
현재 날짜와 미래 날짜는 제외한다. 같은 시간까지의 분봉 누락, 비정상 거래량, 큰 가격 단절이 있으면 해당 일자를 제외한다.
가격 단절 검사는 기업행사·권리락을 정확히 조정하는 기능이 아니므로 수정주가 기반 지표로 해석하지 않는다.
기존 장 마감 보관 자료를 사용하며, 과거 분봉을 대량 다운로드하는 기능은 이번 범위에 포함하지 않았다.

재확인 전략의 허용 오차는 돌파 시점까지의 ATR과 현재 관측 호가 간격을 이용한 연구용 근사치다.
호가 간격은 거래소의 공식 호가 단위와 같다고 보장하지 않는다. 재시험 봉 저점에서 이 간격만큼 아래를 손절 후보로 정한다.
손절이 최대 손실 거리나 비용 반영 손익비와 충돌하면 보류한다. 조건을 맞추려고 손절을 임의로 당기지 않는다.
이전 봉에서 이미 재시험한 신호, 기준선 이탈, 후보 관찰 시작 전 돌파는 재사용하지 않는다.

시장 하락 제한, VWAP, 스프레드, 거래대금, 추격 제한, 매수 시간 등의 공통 기술 조건은 유지된다.
`breakout_retest`는 아직 실제 매매 전략 선택 목록에 넣지 않았다. 비교 결과가 좋더라도 자동 전환하지 않는다.

## 결과 읽기

- **관측**: 동일 종목·완성 봉·설정의 중복을 제거한 자료 수. 동일 봉의 기존 분석과 5분 관찰이 겹치면 5분 관찰을 우선한다.
- **평가 가능**: 해당 비교군에 필요한 근거가 갖춰진 표본 수. 기존 시간 단위 분석만 있는 경우 재확인 전략은 미평가다.
- **기술 통과**: 기술 조건만 통과한 수. BUY 주문이나 뉴스 검토 통과를 의미하지 않는다.
- **경로 측정**: 충분한 후속 분봉으로 가상 진입·청산 결과를 계산한 수.
- **평균 가상 순수익률**: 신호 확인 뒤 다음 사용 가능한 1분 구간 시가로 진입했다고 가정한 경로 평균이다. 실제 체결·계좌 수익률·승률이 아니다.
- **자료 부족 / 미평가**: 거래량 이력, 후보 관찰 시작 기록 또는 후속 가격 자료 부족. 매수 반대 근거와 구분한다.

진입은 신호를 확인한 시각보다 나중에 시작하는 1분 구간만 사용한다. 새 시가에서 진입 시간·추격·손절 거리·손익비를 다시 검사한다.
목표와 손절을 같은 1분봉에서 모두 건드리면 순서를 알 수 없으므로 수익을 부여하지 않는다.
후속 분봉이 빠져 있으면 평가에서 제외한다. 겹치는 신호를 동시에 모두 매수했다고 가정하거나 계좌 수익으로 합산하지 않는다.
보유 수량·예약 자금·당일 재진입 제한까지 재현하는 포트폴리오 백테스트는 아니다.

기존 설정이 기간 중 달라졌다면 관측별 당시 설정으로 계산한다. 단일 고정 설정의 성과라고 해석하지 않는다.
각 관측에는 설정 해시·구성목록 해시·적용 비용이, 비교 결과에는 계산 코드 해시·원자료 식별자가 저장된다.
기존 분석에 없는 구성목록/관찰 시작 시각을 사후에 만들어 넣지 않는다.

## 비용 기준

전략 비교 탭의 **비용 기준**에서 편도 수수료, 매도 세금, 편도 슬리피지, 비교용 왕복 총비용 하한을 입력한다.
모든 입력은 비율이다. 예를 들어 `0.001`은 0.1%다. 세금·수수료는 사용 중인 계좌의 실제 적용 조건을 확인해 직접 입력한다.
기본 0은 실제 비용이 없다는 보장이 아니다.

비교 비용은 다음 중 가장 큰 값을 사용한다. 하한을 비용에 다시 더하지 않는다.

```text
max(관측 당시 estimated_cost_rate,
    2 * 편도 수수료 + 매도 세금 + 2 * 편도 슬리피지,
    비교용 왕복 총비용 하한)
```

**비교 비용 저장**은 연구용 비용 버전만 바꾸고, 계좌나 기존 결과를 수정하지 않는다.
변경한 비용으로 다시 보려면 **저장 자료 비교**를 실행한다. 새 결과는 별도 폴더에 보관된다.

**모의 계좌 비용 적용**은 확인창 승인 후 이후 모의 체결의 수수료·매도 세금·슬리피지를 변경한다.
비교용 하한은 계좌에 적용되지 않는다. 자동 분석 일시정지, 진행·대기 작업 없음, 보유·미확인 주문 없음이 모두 필요하다.
버전과 변경 시점을 기록하며 이전 체결·현금·실현손익은 다시 계산하지 않는다. 실투자 비용은 변경할 수 없다.
입력값을 바꾼 것만으로는 어느 비용도 적용되지 않는다. 비교용 저장과 계좌 적용은 별도 명령이다.

## 관찰과 저장

관찰 후보는 선정 후 최대 60분 동안 유효하고 같은 5분 구간에서 중복 조회하지 않는다.
새 선정 회차, 설정 저장, 대시보드 CSV 재등록, 일시정지·중단 시 관찰을 취소한다. 재시작 시 오래된 후보를 복원하지 않는다.
수동·예약 분석이 진행되면 새 연구 조회를 멈춘다. 이미 시작된 HTTP 요청은 즉시 취소되지 않을 수 있으나 취소·만료 후 도착한 결과는 저장하지 않는다.
읽기 전용 어댑터는 달력·분봉·호가 조회만 허용하고 기존 Toss 읽기 예산·캐시를 공유한다.
외장 드라이브가 없으면 추가 관찰 조회를 시작하지 않는다. 연구 오류가 기존 보유 관리 스케줄러를 중단하지 않도록 분리했다.

```text
/Volumes/External/TradingAgents/strategy_research/<dry-run 또는 live>/<계좌>/
  costs/<버전>.json
  observations/<날짜>/<입력 해시>.json
  comparisons/<비교 ID>/evidence.json
  comparisons/<비교 ID>/report.json
```

대시보드용 최신 결과와 연구 비용 설정은 `.local/strategy_research/<모드>/<계좌>/`에도 저장한다.
모의 체결 비용 이력은 기존 `.local/accounts/paper.sqlite3`의 `cost_profiles` 테이블에 추가된다.
저장 폴더 준비는 `Setup-Postmarket-Storage.command`에서도 수행할 수 있다.

비교는 최근 20개 관측 날짜를 대상으로 한다. 저장된 일별 복기는 최근 최대 60일치, 추가 관찰 파일은 최신 최대 500개·32MB,
합쳐진 관측은 최대 1,000개로 제한한다. 예산 때문에 제외하면 자료 상태에 표시한다. 이 제한도 비교 결과의 표본 범위다.
기존 복기 원자료의 식별자·체크섬·체결 재구성 검증과 관찰 파일의 내용 해시 검증을 거친다.

## 후속 범위

이번 구현은 [조사 계획](intraday_research_plan.md)의 비용·비교 기반·시간대 거래량·돌파 재확인·5분 관찰에 한정한다.
추세형 VWAP 개선, 뉴스 밖 시장자료 후보 확장, 국면별 선택, 새 청산 방식, 포트폴리오 재현, 자동 전략 승격은 미반영이다.
기간을 나눈 검증과 비용 민감도 평가를 마친 뒤 별도 승인으로 주문 경로에 연결해야 한다. 종목별 +1%는 비용 전 목표이지 수익 보장이 아니다.
