# 텔레그램 알림

## 최초 연결

1. `Setup-Telegram.command`를 더블클릭합니다. 공용 가상환경을 사용합니다.
2. BotFather에서 받은 봇 토큰을 입력합니다. 화면에는 표시되지 않습니다.
3. 수신 대화 ID(chat_id)를 입력합니다. 모르면 Enter를 누르고, 표시되는
   `/start 확인문구`를 본인 봇의 개인 대화에 전송한 뒤 Enter를 누릅니다.
4. 표시된 수신 대상이 본인인지 확인하고 `y`를 입력합니다.
   테스트 알림이 성공하면 공용 `.env`에 저장합니다.
5. 실행 중인 TradingAgents를 정상 종료 후 다시 실행합니다.
   대시보드 **설정 > 텔레그램 알림**에서 활성화 및 항목을 선택하고 설정을 저장합니다.

수신 대상은 자동으로 첫 번째 대화를 선택하지 않습니다. 확인문구가 일치하는
개인 대화만 자동 연결합니다. 그룹은 봇을 추가한 후 그룹의 숫자 ID를 직접 입력하세요.
이미 웹훅을 쓰는 다른 봇은 getUpdates 자동 확인이 안 될 수 있으므로 알림 전용 봇을 권장합니다.

## 입력 위치

현재 공용 설정 파일은 `/Users/leejang2/Project/.env`입니다.
설정 도구는 아래 키만 갱신하고 OpenAI·Toss·Naver 등의 기존 값은 보존합니다.
파일 권한은 소유자 전용(600)으로 저장하며 대시보드·로그에 토큰을 노출하지 않습니다.

```dotenv
TRADINGAGENTS_TELEGRAM_ENABLED=1
TRADINGAGENTS_TELEGRAM_BOT_TOKEN=BotFather에서_발급받은_토큰
TRADINGAGENTS_TELEGRAM_CHAT_ID=본인의_숫자_대화_ID
```

직접 편집했다면 프로그램을 다시 실행하세요. 이미 터미널에 export한 같은 이름의
환경변수는 `.env`보다 우선하므로 오래된 값은 해제해야 합니다. 토큰을 Git, 채팅,
브라우저 주소창에 입력하지 마세요. 노출 시 BotFather에서 폐기하고 재발급합니다.

## 알림과 안전

- 시작·종료, 후보 분석 시작·완료, 저장된 주문 상태와 부분/전량 체결, 청산·이월·기한 초과,
  일일 손실 제한, 분석 오류·OpenAI 크레딧 소진 전환, 장 마감 복기를 전송합니다.
- 메시지에 모의/실투자를 구분합니다. 분석 판정과 주문 접수는 체결 완료가 아닙니다.
  체결은 위험 관리 DB의 검증 후 저장된 수량·금액을 읽어 알립니다.
- 설정 전 과거 주문 이력을 한꺼번에 보내지 않습니다. 재시작 후 이미 관측한 주문의
  체결 상태 변경은 다시 확인하며, 반복 점검의 동일 상태는 중복 발송하지 않습니다.
- 알림 전용이며 텔레그램 명령으로 주문·설정 변경을 받지 않습니다. 수익·뉴스 요약을
  만들기 위한 추가 LLM 호출도 없습니다. 종목·수량·체결가 등 전송 정보는 Telegram에 전달됩니다.
- 별도 작업자가 전송하며 매매/청산 코드에서 네트워크 전송을 기다리지 않습니다.
  대기열은 최대 500건, 유효시간 1시간, 전송 이력은 7일 보존합니다.
- 일시 오류는 최대 4회, Telegram 429는 retry_after 이상 기다려 재시도합니다.
  연속 전송은 최소 1.1초 간격입니다.
  401/403은 토큰·봇 차단·대화 권한을 확인하세요. 목적지가 바뀌면 기존 대기 알림은 취소합니다.
- 전송 응답 유실이나 프로세스 종료 시 중복 수신 가능성이 남습니다. 알림 성공은
  휴대폰에서 읽었음을 뜻하지 않으며, 알림 실패 때문에 주문을 재전송하지 않습니다.
- 정상 종료 알림은 제한된 시간 내 최선으로 전송합니다. Mac 전원 차단·강제 종료·인터넷
  단절은 자체 알림을 보장할 수 없으며 필요하면 별도의 외부 감시를 추가해야 합니다.

대시보드 **테스트 알림 전송**은 30초 간격으로 사용할 수 있습니다.
전송 대기와 전송 완료는 구분되며 **최근 전송 내역**에서 확인합니다.
비밀 값은 공용 `.env`, 대기열과 상태는 `.local/notifications/telegram.sqlite3`에 저장됩니다.

HTTPS 연결은 `certifi`의 CA 인증서를 사용하며 서버 인증서와 호스트명을 검증합니다.
Mac Python의 기본 CA 파일이 없어도 이 인증서 경로를 사용합니다. `tls-certificate`
오류가 발생하면 인증서 저장소나 네트워크의 TLS 프록시를 확인하고, 인증서 검증을 끄지 마세요.

API 기준: [Telegram Bot API](https://core.telegram.org/bots/api#sendmessage),
[Telegram 전송 제한 안내](https://core.telegram.org/bots/faq#my-bot-is-hitting-limits-how-do-i-avoid-this).
