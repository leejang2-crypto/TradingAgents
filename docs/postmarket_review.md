# 장 마감 복기와 제한적 매매 반영

휴장일 최근 5거래일 통합 복기는 [주간 복기 안내](weekly_review.md)를 참고하세요.

## 동작 시점

`main.py`의 `daily-market` 모드에서 기본 활성화됩니다. 기본 정규장 종료 후 5분인
15:35부터 실행하며, 거래소 달력이 더 늦은 종료 시각을 알려주면 그 종료 후 5분까지
기다립니다. 설정한 종료 시각이 더 늦으면 그 설정도 존중합니다. 주말·등록 휴장일에는
실행하지 않습니다. 성공한 날짜는 프로그램을 재시작해도 중복 실행하지 않습니다.

프로그램이 켜져 있어야 합니다. 모의/실거래가 모두 같은 복기 구조를 사용하지만
계좌와 자료는 분리됩니다. 수동 매매 일시정지 중에도 읽기 전용 복기는 진행합니다.
자동 복기 자체를 중단하려면 설정의 별도 스위치를 끄세요.

복기는 주문을 보내거나 취소하지 않습니다. 장 종료 지수는 Toss 읽기 API로만
조회하며, 실패하면 `partial` 상태로 기록하고 15분 뒤 재시도합니다. 원자료/디스크
오류가 나도 기존 독립 보유·청산 모니터는 중단시키지 않습니다.

## 저장 위치

기본 경로:

```text
/Volumes/External/TradingAgents/postmarket/
  dry-run/paper/YYYY-MM-DD/<자료 해시>/
  live/<계좌 식별 해시>/YYYY-MM-DD/<자료 해시>/
```

- `review.md`: 시장 관측, 종목별 완결 매매, 순손익, HOLD/진입 차단/분석 오류, 다음 적용 내용.
- `review.json`: 기계가 읽을 수 있는 복기 통계와 검증 결과.
- `policy.json`: 다음 거래일부터 유효한 제한적 신규 진입 규모 조정.
- `opportunities.json`: 후보별 분봉 경로, 가상 진입/목표/손절 도달 구간, 당시 차단 사유.
- `inputs.json.gz`: 해당 일 분석·후보·분봉/호가 재현 자료와 체결 원장, 경험 기록.
- `manifest.json`: 생성 시각, 자료 버전과 원본별 해시.

같은 원자료로 다시 복기하면 같은 폴더를 사용합니다. 뒤늦은 체결 확인 등으로 자료가
바뀌면 새 해시 폴더를 만들어 이전 산출물을 보존합니다. 로그/산출물은 자동 삭제하지 않습니다.
산출물에는 개인 매매 정보가 있으므로 외장 드라이브를 공유하지 마세요. API 키와 `.env`는
수집 대상이 아닙니다. 디렉터리는 0700, 파일은 0600 권한으로 생성합니다.

외장 볼륨이 없으면 해당 이름의 디렉터리를 내부 SSD에 만들거나 대체 저장하지 않습니다.
정책은 **외장 산출물 저장에 성공한 뒤에만** 내부 `.local/postmarket/`에 작은 실행용 캐시로
반영합니다. 외장 저장이 실패하면 새 정책을 반영하지 않고 대시보드에 재시도 상태를 표시합니다.
이미 검증·캐시된 기존 정책은 유효기간 안에서만 사용할 수 있습니다.

### 최초 권한 준비

`Setup-Postmarket-Storage.command`를 Finder에서 더블클릭하면 외장 볼륨 확인 후 폴더를
생성합니다. `Operation not permitted`가 나타나면 macOS **시스템 설정 → 개인정보 보호 및
보안 → 파일 및 폴더**에서 실행 앱(Terminal 또는 Codex)의 외장/이동식 볼륨 접근을 허용하세요.
앱에 따라 항목이 표시되는 이름이 다를 수 있습니다. 폴더 준비 후 실행 앱을 다시 시작합니다.
디스크 포맷, 소유권 변경, `sudo`, 전체 권한 해제는 필요하지 않습니다.

## 복기 기준

- 실제 확인된 주문 누적 체결량을 주문당 한 번만 반영합니다. 부분 매도 여러 번은 완결된
  하나의 매매 주기로 집계합니다. 매수 원가와 매도 대금에서 기록된 수수료·세금을 반영합니다.
- 주문 접수, LLM의 BUY, 가격 상승만으로 체결이나 수익을 추정하지 않습니다. 미확인 주문,
  비용 누락, 알 수 없는 매수 원가, 수량/종목 불일치는 학습 보상에서 제외합니다.
- 표시하는 순손익은 **당일 청산이 완료된 매매 주기**의 손익입니다. 부분 매도만 있었던
  미청산 주기의 당일 실현손익, 계좌 평가손익 또는 계좌 전체 수익률과는 다릅니다.
- KOSPI/KOSDAQ은 최초 실제 관측 분봉 시가부터 마지막 정규장 완성봉까지 비교합니다.
  전일 종가 대비 지수 등락률이 아니며, 첫 1분 누락 등의 한계도 표시합니다.
- 자동 및 대시보드 수동 분석을 경험 DB와 요약 파일에서 모아 중복 제거합니다. 분석
  실패는 HOLD로 바꾸지 않습니다. 놓친 수익은 가상의 수익 보상으로 만들지 않습니다.

## 매매에 반영하는 범위

LLM 가중치 재학습이 아니라, 검증된 체결 통계에 근거한 **제한적 위험 배분 조정**입니다.
추가 OpenAI 비용이나 로컬 LLM 추론은 발생하지 않습니다.

다음 조건을 모두 만족해야 자동 조정합니다.

1. 같은 모의/실계좌, 같은 분석 엔진·진입 전략·매매 기준으로 기록된 완결 매매.
2. 최근 28일 안에 10건 이상, 청산일 기준 3개 거래일 이상.
3. 비용 반영 누적 순손익이 음수이고 승률이 40% 미만.
4. 미확인 주문/체결 불일치가 없고 종가 시장자료까지 정상 수집된 복기.

해당 조건에서만 **신규 매수의 투자금 한도와 1회 위험 예산을 기존 설정의 75%**로 줄입니다.
보유 종목의 청산, 익절 목표 1%, 손절 거리, 일일 손실 한도, 거래량·손익비·추격매수 차단 기준은
변경하지 않습니다. 크기를 늘리거나 손절을 늦추는 자동 최적화는 하지 않습니다.

정책은 복기 다음 날짜부터 7일 이내에만 유효합니다. 실제 실행은 정규장 필터를 거치므로
다음 거래일부터 적용됩니다. 더 최신 정상 복기가 있으면 교체하고, 규칙을 사용자가 바꾸면
이전 규칙의 정책은 적용하지 않습니다. 과거 기록에 전략 기준이 없으면 현재 설정으로 추정해
붙이지 않습니다. 따라서 설치 직후에는 충분한 새 표본이 쌓일 때까지 변경 없음이 정상입니다.

이 10건/3일 기준은 과최적화를 줄이기 위한 운영상 최소치일 뿐 통계적 유의성이나 수익 개선의
보장이 아닙니다. 모의 결과는 실계좌 정책으로 이전하지 않습니다.

## 후보 가격흐름 복기

그날 실제 후보로 저장되었거나 단타 분석 재현 자료가 있는 종목을 대상으로 합니다.
등록한 코스피200 전체를 매번 추가 분석하는 것은 아닙니다. 후보로 **언제 포착되었는지**와
그 시점의 설정을 기록하며, 포착 전에 끝난 상승을 놓친 진입 기회로 세지 않습니다.
기존 자료에 시각/설정/분봉이 없으면 소급해서 만들어내지 않고 `unavailable`로 표시합니다.

장 마감 후 후보의 1분봉을 Toss에서 순차 조회합니다. 1회 전체 조회 예산은 120초,
종목당 최대 20초이며, 429·인증·시간 초과 시 추가 요청을 중단합니다. 완성된 종가 자료는
외장 산출물에서 재사용하고, 실패 종목만 15분 간격으로 최대 3회 수집 시도합니다.
3회 후에도 부족하면 `partial`로 남기고 당일 추가 자동 재시도를 멈춥니다.
분봉 누락·충돌·잘못된 OHLCV는 임의로 보간하지 않습니다. 오프라인 복기는 저장된 구간만
검토하며 종가까지 확인된 것처럼 표시하지 않습니다.

복기는 두 가지를 구분합니다.

1. **사후 가격상 상승 구간**: 후보 포착 후 사용 가능한 분봉 시가에서 이후 고가까지의
   상승폭 상한입니다. 진입 신호·손절·비용을 무시한 사후 관찰이며 실현 가능한 수익이 아닙니다.
   가격은 1% 이상 올랐는데 신호가 없었던 경우, 규칙 차단 사유를 함께 점검할 수 있습니다.
2. **규칙 기반 가상 구간**: 당시까지 완성된 5분봉으로 직전 15분 고점 돌파, 장 초반 범위
   돌파, VWAP 눌림목 회복, VWAP 재돌파를 비교합니다. 현재 매매 엔진과 같은 패턴 함수를
   사용하고 거래대금·상대거래량·VWAP·추격 제한·ATR 손절·비용 반영 손익비도 확인합니다.
   당시 설정 전략과 연구용 비교 전략을 표시하며, 시장 지수는 해당 시점까지의 자료만 씁니다.

가상 진입은 신호 이후 가능한 첫 온전한 1분봉의 시가입니다. 예를 들어 09:20:05에 후보가
확인되었다면 이미 지나간 09:20:00 시가로 매수하지 않고 09:21:00 시가부터 비교합니다.
목표가 선도달, 손절 선도달, 동일 봉 내 순서 불명, 정체 종료, 청산 시각 종료,
후속 자료 부족을 분리합니다. 도달 시각은 정확한 틱 시각이 아니라 **1분 구간**입니다.
갭 하락은 손절가보다 나쁜 시가를 반영하고, 목표/손절을 같은 봉에서 통과하면 이익으로
확정하지 않습니다. 목표 1%는 세전 가격 기준이고 비용 0.3% 설정이면 목표 도달의 단순
비용 차감 추정은 0.7%입니다. 실제 수수료·세금·호가단위·슬리피지·미체결은 다를 수 있습니다.

패턴별 구간은 중첩시키지 않지만, 다른 패턴 간에는 중복될 수 있습니다. 청산 후 재진입도
비교하는 가상 구간이므로 실제 시스템의 당일 재진입 제한, 보유/예산, 30초 점검, 뉴스 위험,
호가 스프레드/잔량, 주문 체결까지 재현한 백테스트는 아닙니다. 구간 수를 실매매 횟수나
승률로 바꾸거나 일일 수익률로 합산하지 않습니다. 기록된 HOLD 등 선행 분석과 그 사유는
해당 가상 구간 옆에 별도로 보관합니다.

### 다음 매매의 참고 자료

기본 `rules-news` 분석은 같은 모드/계좌/종목의 **최근 복기 중 이전 날짜·7일 이내** 자료를
읽어 분석 보고서의 `이전 후보 가격흐름 참고`에 자동 첨부합니다. 종가까지 검증된 자료만
사용하며, 현재 규칙과 같은 가상 구간 최대 3개와 과거 차단 사유를 보여줍니다. 로컬 캐시는
종목당 앞선 12개 구간까지만 보관하므로 전체 기록은 외장 보고서/JSON에서 확인합니다.

참고 자료는 분석 이력과 재현 JSON에도 저장합니다. 추가 LLM 호출이나 OpenAI 토큰은
사용하지 않습니다. 뉴스 분류 프롬프트에는 과거의 가상 성공 사례를 섞지 않습니다.
이 자료로 자동 매수하거나 조건을 완화하지 않고, 오늘 분봉·호가·뉴스·계좌 검사를 그대로
진행합니다. 기존 `multi-agent` 경로는 유지하며, 이 신규 참고 첨부는 기본 단타 경로에 적용됩니다.
가상 수익은 체결 원장이나 위의 75% 규모 조정 정책에 절대 반영하지 않습니다.

## 대시보드 및 수동 복기

**설정 → 단타 매매 기준**에서 `장 마감 자동 복기`, `검증된 복기 결과로 신규 진입 규모 조정`을
각각 켜고 끌 수 있습니다. **분석 → 장 마감 복기**에서 최근 상태, 확인 순손익, 규모 축소 규칙 수,
외장 보고서 경로를 확인합니다. 원본 거래 설정값은 덮어쓰지 않습니다.
같은 접기 영역의 **후보 가격흐름 · 가상 관찰**에서 종목명, 자료 상태, 목표/순서 불명 구간 수,
패턴과 가정 진입/종료 시각도 볼 수 있습니다. 상세 가격·비용·차단 근거는 외장 `review.md`와
`opportunities.json`에 보관합니다.

장 종료 후 특정 날짜를 오프라인으로 복기할 때:

```bash
cd /Users/leejang2/Project/TradingAgents-validation
../.venv/bin/python -m tradingagents.research.postmarket --date 2026-10-28
```

이 명령은 API·LLM·주문을 호출하지 않습니다. 종가 지수를 새로 조회하지 않으므로 `partial`로
기록하고 자동 학습 정책은 활성화하지 않습니다. 실계좌는 `--mode live --risk-db <해당 계좌의
.local/positions/*.sqlite3>`를 명시해야 하며, paper 원장을 live로 표시할 수 없습니다.
과거 날짜의 수동 복기로 더 최신 정책을 덮어쓰지 않습니다.
