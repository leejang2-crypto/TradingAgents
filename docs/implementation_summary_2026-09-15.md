# 최종 반영 요약 (2026-09-15)

대상 브랜치: `feature/daily-paper-trading`.
이 문서는 직전 커밋 이후 누적된 변경을 정리합니다. 개인 설정, API 키, 계좌 정보,
실행 로그 및 SQLite 장부는 Git에 포함하지 않습니다.

## 1. 운용 목표와 매매 기준

- 기본 자본금 1천만 원, 종목당 투자금 상한 10% 유지.
- 계좌 전체 하루 1% 목표에서 **종목별 평균 매입가 대비 +1% 익절**로 변경.
  수수료·세금 차감 전 가격 기준이며, 실제 체결 수익을 보장하지 않습니다.
- Toss 1분봉을 완성 5분봉으로 집계해 VWAP·거래량·거래대금·호가 스프레드·국내 지수 필터 적용.
- 직전 15분 고점 돌파 또는 VWAP 눌림목 회복 전략 선택.
- 종목 손절 최대 0.5%, 일일 손실 한도 2%, 1회 위험 한도 자본의 0.2% 기본값.
- 위험 기반 정수 수량과 매수 지정가 적용. 기존 보유분·미체결 주문의 자본 및 위험도 예약.
- 정체 종목 시간 청산, 연속 손절 제한, 보유 종목 추가 매수·당일 청산 종목 재진입 차단.
- 자료 누락·오래된 시세·미충족 조건은 매수 보류로 기록하며 LLM 판단으로 우회하지 않음.

## 2. 스케줄과 보유 관리

- 정규장 기본 09:00~15:30에 보유 관리 실행. 오전 분석은 분봉 준비 후 09:20, 오후는 13:00.
- 날짜·모드·오전/오후 회차별 실행 예약을 저장해 중단·재시작 시 중복 자동 실행 방지.
- LLM과 독립된 기본 30초 주기 보유 점검. 느린 분봉 조회는 보유 장부 잠금을 점유하지 않음.
- 기본 15:00 신규 매수 중단, 15:15 당일 청산 시작.
- 명시적 종목별 사용자 승인으로만 이월 허용, 매수일 포함 최대 2거래일.
  익절·손절·시간 청산·일일 손실 한도는 이월 허용보다 우선.
- 관리 수량 전량 매도, 부분 체결 반영, 미체결 취소 확인 후 잔량 재주문.
- 접수 응답 유실 시 자동 재전송하지 않음. 접수/취소 응답을 체결 완료로 취급하지 않음.
- 기존 실계좌 보유분은 사용자 확인 없이 자동 편입하지 않음.

## 3. 대시보드와 실행 제어

- 로컬 ID·비밀번호 등록 파일 `Setup-Web-Login.command` 추가.
- 비밀번호 scrypt 저장, 로그인 세션, 요청 위조 방어, 로그인 시도 제한 적용.
- 로그인 후 별도 토큰 입력 없이 상태·계좌·설정·수동 실행 사용. 기존 토큰 API 호환 유지.
- 뉴스 수집, 후보 선정, 분석만 실행, 후보 분석 후 매매 버튼 추가.
- 실행 중 작업이 있으면 중단 후 실행 또는 마무리 후 실행 선택. 대기 취소·자동 분석 일시정지 지원.
- 분석 일시정지와 별개로 보유 관리·청산은 지속. 이미 접수된 주문은 작업 중단으로 되돌리지 않음.
- Latest Analyses에 종목명 표시. 새 결과에 이름 저장, 기존 결과는 종목 코드 일치 후보에서 보완.
- 종목 평균 매입가·수익률·익절/손절가·보유기간·청산 상태·진입 보류 사유 표시.
- 웹에서 분봉 전략, 익절/손절, 위험 한도, 비용 추정 및 운영 시간 변경 가능.

## 4. 계좌·뉴스·LLM

- 모의 계좌 SQLite 장부에 현금·보유 수량·가상 체결·실현손익·평가 내역 저장.
- 일·주·월·년 평가 수익률 조회. 실계좌는 Toss가 제공하는 보유·주문·매수 가능 금액을 표시하며,
  API가 제공하지 않는 실제 계좌 기간 수익률을 임의 계산하지 않음.
- 모의/실전 장부와 경험 기록 분리. 기존 경험 검색은 모델 가중치 재훈련이 아님.
- 기본 제공자는 역할별 혼합: 뉴스 Ollama, 나머지 OpenAI. 기존 웹 저장 설정 우선.
- 로컬 뉴스는 기사/발췌 ID를 선택하고 원문으로 렌더링하여 근거에 없는 생성 문장을 배제.
- 공용 가상환경·`.env`, 원클릭 실행 파일, Tailscale 접속 구조 유지.

## 5. 검증과 적용

- 전체 테스트: 866 passed, 2 skipped. 선택 의존성 `langchain_aws` 미설치와 DeepSeek 키 미설정으로 건너뜀.
- Python 정적 오류 검사, Git 공백 검사 및 JavaScript 구문 검사 통과.
- 합성 데이터 웹 서버로 로그인, 설정 저장, 보유 관리 표시, PC 및 390/320px 모바일 폭 검증.
- 실제 주문이나 유료 LLM을 사용한 실거래 검증은 수행하지 않음. 성과가 검증된 전략으로 해석하면 안 됨.
- 적용하려면 기존 프로그램을 종료한 뒤 `Start-DryRun.command`를 재실행. 실투자는 별도 실행 파일 사용.
- 새 설정은 다음 실행 시 기존 설정과 병합. 기존 잔고·체결 이력·모델 설정을 초기화하지 않음.

제한: 틱 기반 정확한 VWAP, 과거 동일 시간대 상대 거래량, 업종 자동 분류, 차트 시각화,
실제 분봉 이력에 대한 수익성 백테스트는 포함하지 않습니다. 기존 모의 장부의 비용 가정은
유지하며, 새 왕복 비용 추정 설정은 진입 손익비·위험 계산용입니다.
