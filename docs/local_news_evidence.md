# 로컬 뉴스 근거 선택 방식

## 변경 이유

기존 `Local news generated a claim absent from its cited excerpt.` 오류는 모델이
반환한 인용문이 지정한 기사에 없을 때 발생했습니다. 잘못된 사실 생성뿐 아니라
의역, 문장부호 변경, 다른 기사 인용도 원인이 될 수 있습니다.

이제 로컬 뉴스 모델은 인용문을 작성하지 않고 Python이 만든 기사·발췌문 번호만
선택합니다. 이 변경은 `news_local_single_pass` 경로에 적용되며 OpenAI 뉴스 분석
경로와 웹페이지의 LLM 선택 기능은 그대로 유지됩니다.

## 처리 순서

1. Python이 해당 종목의 최근 7일 뉴스 검색 자료를 가져옵니다.
2. 기존 입력 한도인 14,000자, 최대 6개 기사를 유지합니다.
3. 기사 제목과 내용 줄을 발췌문으로 나누고 기사별 번호를 부여합니다.
   링크 전용 줄과 자료 형식 안내 줄은 제외합니다. 발췌문은 10~800자,
   기사당 최대 24개입니다. 긴 문장은 잘릴 수 있으므로 완전한 문장 단위는 아닙니다.
4. 로컬 모델은 한 번의 호출로 1~6개 발췌문 번호와 분류만 반환합니다.
5. Python이 현재 요청의 번호 목록에서 원문을 가져와 기존 원문 포함 여부 검증을
   다시 수행한 후 보고서를 만듭니다. 기사 제목과 링크도 입력 자료에서만 가져옵니다.
6. 후속 에이전트에는 이 검증된 보고서가 전달됩니다.

반환 형식 예시:

```json
{"ticker":"005930.KS","items":[{"article":1,"excerpt":2,"signal":"catalyst"}]}
```

`signal`은 `catalyst`, `risk`, `uncertainty`, `neutral` 중 하나입니다.
번호는 현재 요청에만 유효하며 과거 학습 메모리의 번호를 재사용하지 않습니다.
모델이 추가한 `quote`, 설명, 회사명, URL 등은 보고서에 반영하지 않습니다.

## 실패 및 한계

- 존재하지 않는 번호, 중복 선택, 잘못된 종목·분류, 비정상 JSON은 오류로 차단합니다.
- 발췌 가능한 자료가 없으면 LLM 호출 전에 오류를 반환합니다.
- 실패 시 유료 OpenAI 자동 재시도는 하지 않습니다.
- 기존 `render_verified_news`는 이전 인용문 형식과 내부 검증용으로 유지합니다.
- 원문 일치는 사실 확인이나 분류의 정확성을 보장하지 않습니다. 모델이 관련성이
  낮은 기사를 선택하거나 촉매·위험 분류를 잘못할 수 있습니다.
- 네이버 검색 결과의 제목·요약이 근거이며 기사 전문 수집 기능은 아닙니다.

실행 중인 프로세스에는 수정이 자동 반영되지 않으므로 다음 실행부터 적용됩니다.
운영 실행기를 중복 실행하지 말고 기존 실행을 종료한 뒤 다시 실행하십시오.
